## 目标

端到端重建 P2 的两个中间产物，验证 schema、uid 稳定性、邻接图、v1.4 oracle 计算与
确定性，并分别形成 G2-a、G2-b、G2-c 原始证据。G2-c 的 4 条经销商结果必须逐条
报告，不得做中位数或其他聚合；`iou < 0.90` 是 P2b 触发条件，不是隐藏或重算真实
数字的理由。

## 输入（相对仓库根；schema 已内联）

```json
// data/pilot/units.json
{"crs":"GCJ-02","units":[{"uid":0,"key":"str","district_code":"440105","street":"str","area_km2":1.0,"centroid":[113.0,23.0],"geom":"<Polygon或MultiPolygon WKT>"}]}

// data/pilot/fences_dealer.json 与 fences_yeidai.json
{"fences":[{"name":"str","src_id":"str","area_km2":1.0,"center":[113.0,23.0],"overlap_ratio":0.999,"geom":"<Polygon或MultiPolygon WKT>"}]}
```

真实条件：224 单元、17 条业代围栏、4 条经销商围栏，全部为 GCJ-02；
`uid == units 数组下标`，`LINK_MIN_M = 50`。禁止坐标转换、门店真值、NLP、LLM、
DSL 或求解器。

## v1.4 冻结定义（完整内联）

对每条围栏 `F`：

```python
selected = [u for u in units if fence_geom(F).covers(Point(u["centroid"]))]
U = unary_union([geom(u) for u in selected])

iou = area(U.intersection(F)) / area(U.union(F))
recall = area(U.intersection(F)) / area(F)
precision = area(U.intersection(F)) / area(U)
straddle = count(
    0.2 <= area(geom(u).intersection(F)) / area(geom(u)) <= 0.8
    for u in units
)
components = connected_components(
    unit_graph induced by {u["uid"] for u in selected}
)
```

- oracle 选取必须使用 `covers`，含边界；质心恰在边界上的“围栏 × 单元”组合总数
  必须落盘为顶层 `boundary_centroids`。正常应为 0，大于 0 不阻断，但须原值报告。
- `straddle` 使用闭区间 `[0.2, 0.8]`。
- `components` 是选中单元在 `unit_graph.json` 诱导子图中的连通分量数。
- `iou` 是 G2-b/G2-c 的唯一判据。`recall` 与 `precision` 仅用于解释漏选和溢出，
  不参与门禁；禁止把 `recall` 当成绩。
- 禁止修改公式、边界规则、样本或真实数字追求通过。

门禁判据精确为：

```python
assert len(yeidai_values) == 17
G2_b_pass = statistics.median(v["iou"] for v in yeidai_values) >= 0.95

assert len(dealer_values) == 4
p2b_triggered = any(v["iou"] < 0.90 for v in dealer_values)
```

- G2-b：业代 n=17，`median(iou) >= 0.95` 才 PASS。
- G2-c：无预设通过线；逐条报告
  `src_id/iou/recall/precision/straddle/components`，不报中位数。任一条
  `iou < 0.90` 时触发 P2b，但不得把它记作 G2-c 失败。
- 主线全市口径业代中位 `0.970`、经销商中位 `0.764` 只作对标参照，不增加门禁。

## 输出（相对仓库根；schema 已内联）

只允许以下两个 P2 数据产物：

```json
// data/pilot/unit_graph.json
{"adjacency":{"<uid>":[0,1]},"link_min_m":50}

// data/pilot/oracle_unitsets.json
{"method":"3.6-v1.4","link_min_m":50,"boundary_centroids":0,"fences":{"<src_id>":{"name":"str","layer":"dealer","unit_ids":[0,1],"iou":0.97,"recall":0.98,"precision":0.99,"straddle":0,"components":1}}}
```

`oracle_unitsets.json` 的精确 schema 约束：

- 顶层键恰为 `method/link_min_m/boundary_centroids/fences`；`method == "3.6-v1.4"`，
  `link_min_m == 50`。
- `fences` 恰有 21 个键；每项键恰为
  `name/layer/unit_ids/iou/recall/precision/straddle/components`。
- `unit_ids` 升序唯一，值域 `0..223`；`layer` 只允许 `dealer`/`yeidai`。
- `iou/recall/precision` 是 `[0,1]` 内有限数；`straddle`、`boundary_centroids`
  是非负整数；`components` 是正整数。
- 两个产物均按冻结顺序写紧凑 UTF-8 JSON，原子替换；同一输入双跑字节一致。

CLI 汇总必须精确分为三段，不写第三个报告文件：

```text
G2-a overlap_ratio=<数值> isolated=<整数> edges=<整数>
G2-b yeidai_n=17 median_iou=<数值> result=PASS|FAIL
G2-c dealer src_id=<id> iou=<数值> recall=<数值> precision=<数值> straddle=<整数> components=<整数> p2b=YES|NO
...共4行...
G2-c p2b_triggered=YES|NO
```

不得输出经销商中位数或等价聚合。`boundary_centroids > 0` 时另输出一行精简告警并原值
报告，但不改变 G2-b/G2-c 结果。
