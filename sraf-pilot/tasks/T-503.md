## 输入与输出 schema（相对仓库根；完整内联）

```jsonc
// data/pilot/units.json
{"crs":"GCJ-02","units":[{"uid":0,"key":"源主键","district_code":"440105","street":"街道名","area_km2":1.0,"centroid":[113.0,23.0],"geom":"<Polygon或MultiPolygon WKT>"}]}

{"schema_version":"p5-lines-v1","crs":"GCJ-02","source_crs":"WGS-84","source_sha256":"<sha256>","counts":{"source_elements":45772,"source_named_ways":13945,"output_names":1234,"output_parts":13945},"lines":[{"name":"华南快速","classes":["highway"],"osm_way_ids":[123,456],"geom":"<LineString或MultiLineString WKT>"}]}
```

其余上下文为 `streets.json/districts.json/unit_graph.json`，schema 与 T-502 相同。最终输出
必须恰为：

```json

```

`unit_ids` 升序唯一；`components` 仅为选中 uid 在 L1 `unit_graph.json` 诱导子图的分量数；
`area_km2` 仍用单元字段稳定求和；`rule` 深拷贝原样回填；`warnings=[]`。P5 不读 L2 细面。

## `side_of` 冻结求值算法（L2 不得自行选近似）

规则：

```jsonc
{"op":"side_of","line":"华南快速","dir":"东北","scope":<node|null>}
```

按以下顺序执行：

1. 用 T-502 的 `resolve_line` 唯一解析 `line`；0 或 >1 匹配立即抛 `DslError`。
2. `scope` 省略或 null 时，候选是全部 L1 uid；非空时**先**递归求值 scope，候选严格等于
   scope 集合。scope 若为空，立即中文抛错，不进入线侧判断。
3. LineString 视为一个 part；MultiLineString 只通过 `.geoms` 展开。按
   `osm_way_ids`/part 顺序，再按 part 坐标顺序枚举相邻点段；不得裸用 `.exterior`，不得把
   多段线简化成首尾“整线走向”。零长度段拒绝输入或跳过已被其他有效段覆盖的重复点，若
   命中线最终无有效段则抛错。
4. 对每个候选单元仅使用 `units.json` 已落盘的**质心** P。对每一线段 AB，在 P 所在纬度
   建立局部东西/南北平面：相对经度差乘 `cos(radians(P.lat))`，相对纬度差不变；共同尺度
   不参与距离报告。计算 P 到线段的钳制投影 Q，选择平方距离最小的段；距离在
   `1e-15` 内并列时按 part index、segment index 较小者，保证确定性。该段 AB 就是最近点
   Q 的**局部切线**，禁止使用整条线首尾向量、全线 PCA 或 bbox。
5. 局部切线 `t = B-A`；`r = P-Q`。八方位向量冻结为：
   `北=(0,1)、南=(0,-1)、东=(1,0)、西=(-1,0)、东北=(1,1)、东南=(1,-1)、
   西北=(-1,1)、西南=(-1,-1)`。
6. 计算二维叉积 `side_p=cross(t,r)` 与 `side_dir=cross(t,dir_vector)`。仅当
   `abs(side_p)>1e-12`、`abs(side_dir)>1e-12` 且 `side_p*side_dir>0` 时选中。
   这表示 P 与请求方向位于该**局部切线的同一有向侧**；反转 OSM 线点序会同时反转两项，
   结果不变。质心在线上或请求方向恰与局部切线平行时该候选不入选，不猜测。

以上计算只用于局部方向符号，不是球面距离换算；全程坐标已是 GCJ-02，不再转换。

## `near` 冻结求值算法

```jsonc
{"op":"near","center":[113.30,23.10],"radius_km":3.0}
```

- 候选固定为全部 L1 单元；逐单元严格调用
  `intelligence.world.haversine_km(tuple(unit["centroid"]), tuple(center))`。
- 当且仅当返回距离 `<= radius_km` 时选中，等号必须包含。禁止自写 haversine、经纬度差
  乘常数、Shapely degree distance、投影距离或坐标转换。
- `radius_km == 0` 合法；center 恰等于某单元质心时该单元必须选中。

## “至少保留一项”冻结纪律与 P3 兼容边界

快速实验曾出现所有候选评分为负 → 全部丢弃 → 空集 → Jaccard 归零。P5 必须同时做到：

- `side_of` 或 `near` 自身结果为空时，显式抛 `DslError`，消息含 op、规则定位与原因；
  不得返回 `set()`、不得 warning 后继续。
- 任意**包含至少一个 P5 原语**的完整表达式，经 union/minus 组装后最终为空，也必须在
  `eval_rule` 顶层显式抛 `DslError`。可用只读树扫描判断是否含 P5 op，不得修改规则。
- 纯 P3 规则保持 v1.7 语义：`minus(X,X)` 仍可合法返回空集，`execute` 仍返回
  `unit_ids=[]/components=0/area_km2=0.0`。不得为 P5 约束破坏 G3 既有退化用例。
- 本阶段没有贪心优选器，不得新增启发式打分；上面是执行器边界的非空保证。
