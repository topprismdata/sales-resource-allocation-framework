## 六原语 schema（字段集合与类型冻结）

既有四原语及语义不得变化：

```jsonc
{"op":"in_street","name":"南石头街道"}
{"op":"in_district","name":"海珠区"}
{"op":"union","args":[<node>,<node>,...]}
{"op":"minus","args":[<node>,<node>]}
```

P5 两原语：

```jsonc
{"op":"side_of","line":"华南快速","dir":"东北","scope":<node|null>}
{"op":"near","center":[113.30,23.10],"radius_km":3.0}
```

- `side_of` 字段只允许 `op/line/dir/scope`。`line` 必须为非空字符串；`dir` 必须恰为
  `北/南/东/西/东北/东南/西北/西南` 之一，不接受英文、缩写、组合词或模糊匹配。
- `scope` 可省略或显式为 `null`，两者均表示全试点 224 单元；非空时必须是递归合法的
  六原语节点。校验位置必须延续 `$.scope...`，深度与循环保护沿用现有上限。
- `near` 字段必须恰为 `op/center/radius_km`。`center` 为长度 2 的 JSON 数组
  `[lon,lat]`，元素必须是有限数字且 bool 不算数字，范围分别为 `[-180,180]`、
  `[-90,90]`；`radius_km` 为有限非负数字，**0 合法**，bool 非法。
- 任一额外字段、缺字段、tuple 代替 JSON array、非法数值、未知 op 均抛 `DslError`；
  不得修正、补默认值或改写传入规则。`scope` 省略的默认行为只在求值时解释，不回写树。

## 线要素加载与三级名称解析

- `load_pilot_context(data_dir)` 在既有四文件之外必须加载同目录 `lines.json`，返回新增
  `lines/line_geoms`；旧字段内容与含义不变。
- 顶层/行字段必须恰与 schema 相同；`schema_version/crs/source_crs` 分别严格等于
  `p5-lines-v1/GCJ-02/WGS-84`；sha256 格式合法；counts 均为非负整数且 bool 非法。
- `name` 非空且全表唯一；`classes` 是 `highway/waterway/railway` 的非空升序唯一数组；
  `osm_way_ids` 为非空升序唯一正整数数组；`geom` 仅接受非空
  LineString/MultiLineString，每个 part 至少两个不同点。
- 交叉断言：`output_names == len(lines)`；`output_parts == sum(len(osm_way_ids))`；
  几何 part 数必须等于该行 `osm_way_ids` 数。加载失败中文报路径和行号。
- `resolve_line(query, lines)` 严格复用现有 §4.3 三级阶段机：
  **精确 → 去末尾后缀（沿用现有 `街道/镇/区` 规则）→ 包含匹配**；某一级唯一才返回。
  匹配 0 个或大于 1 个一律 `DslError`。不得新增两字前缀、拼音、`ref`、别名或道路等级
  猜测，不得跨到街道/区县表。精确同名 way 已由 T-501 聚合，不构成多匹配。

## P5 三条冻结约束（不得打折）

1. 八方位全部进入 schema，不得退回四方位：快速实验 0.6765 → 0.7931，斜向贡献
   0.12。
2. 任何含 P5 原语的表达式最终不得静默返回空集；T-503 将实现“非空或显式抛错”。本卡
   必须先拒绝尚未实现的 P5 求值，不能用空集合占位。
3. `side_of` 无法解决街道 6.7% 级小片区，留给 P6 细面；本卡不得增加隐式 buffer、
   道路等级优选、名称猜测或调参兜底。

## 求值语义（完整卡载；T-503 必须原样承接）

- `side_of`：单元**质心**相对命中线的**最近点局部切线**的有向侧，**不是整线走向**；
  `scope` 非空时必须先求值并缩小候选集。
- `near`：单元质心到 `center` 的球面距离 `<= radius_km`；必须直接复用
  `intelligence.world.haversine_km`，禁止自写距离、度数/公里换算或坐标转换。
- 线名按上面的三级容错；匹配 0 或 >1 必须抛错，禁止复刻主线
  `lookup_geometry` 两字前缀静默兜底。

## 可执行验收断言

用临时目录手写最小五文件，至少断言：

```python
ctx = load_pilot_context(tmp_data)
assert ctx["crs"] == "GCJ-02"
assert [row["name"] for row in ctx["lines"]] == ["人民桥", "人民路", "华南快速"]
```
