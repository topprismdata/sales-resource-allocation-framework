def evaluate_g4_rule_path(cases: list[dict], ctx: dict) -> dict: ...

逐条结果 schema 精确为：

```json
{
  "label":"[合成语料]",
  "case_id":"G4-001",
  "layer":"dealer",
  "description":"凤阳街道、华洲街道",
  "parse_success":true,
  "path":"rule",
  "llm_unavailable":true,
  "rule":{"op":"union","args":[{"op":"in_street","name":"凤阳街道"},{"op":"in_street","name":"华洲街道"}]},
  "predicted_unit_ids":[1,2],
  "jaccard":0.6666666666666666,
  "predicted_components":1,
  "expected_components":1,
  "components_correct":true,
  "error":null
}
```

示例中的 `rule` 是合法的两参并集；真实输出也必须是通过 `validate_rule` 的完整树。
失败行保持同一键集合：`parse_success=false`、`path=null`、`rule=null`、
`predicted_unit_ids=[]`、`jaccard=0.0`、`predicted_components=null`、
`components_correct=false`、`error=<中文精简原因>`、`llm_unavailable=true`。

汇总 schema 精确为：

```json
{
  "label":"[合成语料]",
  "n":21,
  "rows":[...],
  "median_jaccard":0.75,
  "components_correct":15,
  "components_accuracy":0.7142857142857143,
  "rule_parse_success":21,
  "rule_parse_rate":1.0,
  "parse_failures":[],
  "rule_path_only":true,
  "llm_evaluated":false,
  "has_preset_pass_line":false
}
```

指标冻结：

```python
J = len(predicted & oracle) / len(predicted | oracle)
median_jaccard = statistics.median(row["jaccard"] for row in rows)
components_correct = sum(predicted_components == expected_components for each successful row)
components_accuracy = components_correct / 21
rule_parse_rate = rule_parse_success / 21
```

oracle 本轮全部非空；若输入出现空 oracle，按输入契约错误停止，不自行定义空并空得分。
规则解析失败不调用 LLM，按 `jaccard=0.0`、components 不正确纳入 21 条分母，并进入
`parse_failures`，不得删样本或只对成功样本算中位数。

## G4 运行路径纪律

- 必须直接调用 `parse_rule_deterministic`，然后调用 `03_dsl.execute`；不得调用 LLM
  adapter、HTTP、`compile_description` 的兜底分支或读取 `--llm-config`。
- 每个成功结果的 `path` 必须为 `rule`，`llm_unavailable=true`；全局
  `rule_path_only=true`、`llm_evaluated=false`。
- predicted components 必须取 03 五字段输出，expected components 取 oracle case；禁止
  用 street 数量、几何环数、L2 细面或另一套 helper 重算 predicted。
- Jaccard 只比较 uid 集合；不得使用 P2 oracle 里的几何 `iou/recall/precision` 替代。
- 不预设阈值，不输出 G4 PASS/FAIL，不因分数低而改合成文本、删样本或重跑追数。
