# T-103 — P1 围栏筛区、规范化与脏点留档

## 状态与依赖

- 阶段：P1
- 依赖：T-101 完成；T-102 已生成两个试点区县几何；G0 经 L0 签字。
- 后继：T-104、T-105。
- 当前冻结点：契约没有定义“围栏属于试点区”的空间判定、`src_id` 来源，也没有批准重复名的保留/删除规则。L0 回复前不得派发本卡。
- 施工范围：只允许增量修改 `sraf-pilot/src/01_extract.py` 与 `sraf-pilot/tests/test_01_extract.py`。

## 目标

只读抽取经销商与业代围栏，写出统一 fence schema；发现并完整记录同名不同位置脏点。
不得以围栏名自行去重，不得修改源 CSV，不得使用门店位置作为真值。

## 输入（相对仓库根）

1. `<SRC_DIR>/广州办事处经销商围栏数据-20260827.csv`
2. `<SRC_DIR>/广州清单内业代的围栏数据-20260824.csv`
3. `data/pilot/districts.json`

两份 CSV 编码均为 `utf-8-sig`，读取前必须执行：

```python
csv.field_size_limit(sys.maxsize)
```

CSV 必需字段：

```text
围栏名称, fence, 中心点经度, 中心点纬度, 围栏面积
```

业代 CSV 另需：

```text
办事处名称
```

注意：上表是核验基线，不等于授权删除任一记录。L0 必须明确：

1. 试点筛区按中心点落区、质心落区、相交即入选，还是面积占比；
2. `src_id` 使用哪个源字段，若源表无 id 是否可用稳定行号；
3. 重复名是全部保留并区分 `src_id`，还是排除指定异常记录。

## 输出（相对仓库根）

`data/pilot/fences_dealer.json` 与 `data/pilot/fences_yeidai.json`：

```json
{"fences":[{"name":"围栏名称","src_id":"稳定源标识","area_km2":1.0,"center":[113.0,23.0],"geom":"<WKT>"}]}
```

`data/pilot/data_issues.md` 必须是人可读 Markdown，至少包含：

- 源文件名；
- 每组重复名的原始行号或获批 `src_id`、面积、中心点；
- 是否进入试点输出以及依据的 L0 决议编号；
- 不得写“按常识”“看起来异常”等无数字判断。

## 可执行验收断言

L0 把三项决议补入本卡后，单测必须逐项断言：

```python
assert set(fence) == {"name","src_id","area_km2","center","geom"}
assert isinstance(fence["name"], str) and fence["name"]
assert isinstance(fence["src_id"], str) and fence["src_id"]
assert isinstance(fence["area_km2"], float) and fence["area_km2"] > 0
assert len(fence["center"]) == 2
assert all(isinstance(v, float) for v in fence["center"])
assert wkt.loads(fence["geom"]).is_empty is False
assert len({f["src_id"] for f in dealer_fences}) == len(dealer_fences)
assert len({f["src_id"] for f in yeidai_fences}) == len(yeidai_fences)
```

还必须断言：

- 合成夹具中区外围栏严格按获批规则被排除，跨区围栏严格按获批规则得到唯一结果。
- 同名不同 `src_id` 不得被字典覆盖；输出顺序确定，连续运行两次字节相同。
- `data_issues.md` 同时包含 `海珠荔湾07`、`番禺08`、`白云南03`、各自次数 `2` 以及两组面积/中心点数字。
- 源 CSV 任一行字段无效时必须中文报错并退出非零，不得生成半成品 JSON。
- 输出中每条围栏均满足获批试点筛区断言，且两类围栏都至少一条；具体数量不得硬编码，实际值写 JOURNAL。
