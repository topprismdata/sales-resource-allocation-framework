## CONTRACTS v1.5 冻结块（完整内联）

P3-MVP 仅：

```jsonc
{"op":"in_street","name":"南石头街道"}
{"op":"in_district","name":"海珠区"}
{"op":"union","args":[<node>,<node>,...]}
{"op":"minus","args":[<node>,<node>]}
```

求值语义：`in_street` 严格按
`street_geom.contains(Point(unit["centroid"]))`；`in_district` 只按
`district_code == 解析出的区编码`；`union` 是集合并；`minus` 是
`eval(args[0]) - eval(args[1])`。`side_of/near` 属 P3b，本轮不做。

名称解析严格为精确 → 去末尾后缀（街道/镇/区）→ 包含匹配；唯一才成功；0 个或
大于 1 个均抛错。禁止静默取首个、两字前缀兜底和跨类型查找。

输出 schema 精确为：

```json
{
  "unit_ids":[12,13,40],
  "components":2,
  "area_km2":31.7,
  "rule":{"op":"union","args":[{"op":"in_street","name":"南石头街道"},{"op":"in_street","name":"彩虹街道"}]},
  "warnings":[]
}
```

- 顶层键恰为 `unit_ids/components/area_km2/rule/warnings`。
- `unit_ids` 为求值集合的升序唯一整数数组。
- `components` 是这些 uid 在 `data/pilot/unit_graph.json` **L1 诱导子图**中的连通
  分量数；空集合为 0，非空集合至少 1。D-9：只报告，不干预结果。
- `area_km2` 为所选 L1 单元在 `units.json` 中 `area_km2` 的确定性求和；空集合为
  `0.0`，必须是有限非负数。不得用几何 union/difference 或 L2 细面重算。
- `rule` 原样回填调用者传入的 DSL 树；执行前后不得修改该对象。
- `warnings` 是字符串数组。v1.5 对 P3-MVP 未定义非致命 warning，成功结果返回 `[]`；
  名称 0 匹配或歧义是异常，绝不能降级为 warning。

G3 七类退化用例（T-304 全量门禁）为：不存在街道抛错、单单元、minus 空集、union
重复幂等、多分量、名称歧义抛错、嵌套至少 3 层。G3 必须 100%，expected 必须由人工
枚举或直接筛 raw units 字段独立得到，禁止调用生产求值/汇总 helper 自证。
