# T-201 — P2 输入校验与 uid 冻结映射

## 状态与依赖

- 阶段：P2
- 状态：**READY**。
- 依赖：P1/G1 已由 L0 独立验收 PASS；7 个 P1 产物已存在。
- 后继：T-202、T-203。
- 施工范围：只允许新增/修改 `sraf-pilot/src/02_units.py` 与
  `sraf-pilot/tests/test_02_units.py`；不得修改 `01_extract.py` 或 P1 单测。

## 目标

建立 P2 的只读输入层，严格校验 P1 的单元与围栏产物，并构造稳定的
`key -> uid` 映射。只做校验与纯函数，不生成 P2 最终 JSON；不得重排、重编号或修补
`units.json`，不得做坐标转换。

## 输入（相对仓库根；schema 已内联）

CLI 形态固定为：

```bash
python3 sraf-pilot/src/02_units.py --data data/pilot
```

`--data` 必须由调用者显式传入；代码中禁止 `/Users/...` 等绝对路径。

`data/pilot/units.json`：

```json
{"crs":"GCJ-02","units":[{"uid":0,"key":"源主键","district_code":"440105","street":"街道名","area_km2":1.0,"centroid":[113.0,23.0],"geom":"<Polygon或MultiPolygon WKT>"}]}
```

`data/pilot/fences_dealer.json` 与 `data/pilot/fences_yeidai.json`：

```json
{"fences":[{"name":"围栏名称","src_id":"片区id原值","area_km2":1.0,"center":[113.0,23.0],"overlap_ratio":0.999,"geom":"<Polygon或MultiPolygon WKT>"}]}
```

真实数据条件：单元 224 个；经销商围栏 4 条；业代围栏 17 条；全体为同一
GCJ-02 坐标系，禁止转换。`src_id` 在各输入文件内必须唯一；在写入同一个
`oracle_unitsets.json` 前还必须验证两类围栏之间也无 `src_id` 冲突。

## 输出

代码输出仅限：

- `sraf-pilot/src/02_units.py`
- `sraf-pilot/tests/test_02_units.py`

模块必须提供可单测的纯函数，至少能完成：加载 JSON、schema 校验、WKT 解析、
`build_key_uid_map(units)`。映射定义必须严格是：

```python
key_to_uid = {unit["key"]: unit["uid"] for unit in units}
```

本卡不额外创建第三种数据产物；`key -> uid` 映射由模块纯函数产出并由后继卡使用。
本卡不得创建 `data/pilot/unit_graph.json` 或 `data/pilot/oracle_unitsets.json`。

## 实现纪律（已内联）

- Python 3.11+；路径使用 `pathlib.Path`；JSON 使用 UTF-8。
- 注释/docstring 与业务错误信息使用中文。
- 几何只接受非空的 Polygon 或 MultiPolygon；不得直接假设存在 `.exterior`。
- `uid` 必须等于 `units` 数组下标且为 `0..N-1`；禁止按 `key`、面积或街道重排。
- `key` 必须为非空字符串且全局唯一；重复即中文报错，不得覆盖。
- `centroid` 只作输入校验，不得重新计算并覆写。
- 输入只读；任何失败不得产生半成品 JSON；不得访问网络。
- 不得修改 `CONTRACTS.md`、`00_BRIEF.md`、`ROUTING.md`、`JOURNAL.md`、
  `state.json`，不得执行 git commit/push。

## 可执行验收断言

`sraf-pilot/tests/test_02_units.py` 使用 `unittest` 与临时目录，至少覆盖：

```python
assert payload["crs"] == "GCJ-02"
assert [u["uid"] for u in units] == list(range(len(units)))
assert len({u["key"] for u in units}) == len(units)
assert key_to_uid == {u["key"]: u["uid"] for u in units}
assert len(key_to_uid) == len(units)
assert all(geom.geom_type in {"Polygon", "MultiPolygon"} for geom in unit_geoms)
assert all(not geom.is_empty for geom in unit_geoms)
assert len({f["src_id"] for f in dealer_fences}) == len(dealer_fences)
assert len({f["src_id"] for f in yeidai_fences}) == len(yeidai_fences)
assert set(f["src_id"] for f in dealer_fences).isdisjoint(
    f["src_id"] for f in yeidai_fences
)
```

还必须断言以下情况抛出含路径和中文原因的异常：文件缺失、JSON 非对象、顶层键缺失、
字段集合不符、`uid` 非整数/不连续/不等于数组下标、空或重复 `key`、非法/空 WKT、
非 Polygon/MultiPolygon、两类围栏 `src_id` 冲突。用合成 MultiPolygon 证明代码没有
直接读取 `.exterior`。

运行：

```bash
python3 -m unittest sraf-pilot/tests/test_02_units.py -q
```

预期退出码 `0`，且两个 P2 数据产物均未被创建。
