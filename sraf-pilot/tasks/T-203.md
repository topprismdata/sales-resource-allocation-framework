## 目标

回答纯表示能力问题：“如果事先知道答案，能否用这些单元精确拼出这个围栏”。
本卡不得使用 NLP、LLM、DSL、求解器、门店位置或坐标转换；只根据真实围栏几何、
单元几何和已冻结邻接图生成 oracle 单元集，并计算 v1.4 冻结指标。

## 冻结算法（CONTRACTS v1.4 §3.6，完整内联）

对每条围栏 `F`，使用 `units.json` 已落盘的 `centroid` 构造点，oracle 单元集定义为：

```python
U(F) = {u: fence_geom(F).covers(Point(u["centroid"]))}
```

- 必须使用 `covers`，含质心恰落围栏边界的单元；禁止改用 `contains`。
- 对每个“围栏 × 单元”组合另行判断质心是否恰在 `F.boundary` 上，并把总数写入
  顶层 `boundary_centroids`。正常应为 `0`；大于 `0` 时仍继续生成产物，但必须在
  返回摘要中原值报告，供 L1 追加 JOURNAL。
- `unit_ids` 必须升序、唯一，并全部存在于 `units.json`。

设 `U = unary_union(选中单元几何)`，`F = 当前围栏几何`，指标唯一公式为：

```python
iou = area(U.intersection(F)) / area(U.union(F))
recall = area(U.intersection(F)) / area(F)
precision = area(U.intersection(F)) / area(U)
straddle = count(
    0.2 <= area(u.intersection(F)) / area(u) <= 0.8
    for u in 全部试点单元
)
```

- `iou` 是 G2-b/G2-c 的唯一判据。
- `recall`、`precision` 只作诊断，不参与任何门禁；禁止把 `recall` 当成绩报告。
- `straddle` 必须使用闭区间 `[0.2, 0.8]`，恰为 `0.2` 或 `0.8` 均计入。
- 面积计算使用同一批 GCJ-02 Shapely 几何的平面面积，比例无量纲。
- 不得为追数修改公式、边界包含规则或样本。
- 若 `area(F) <= 0`、任一参与计算的 `area(u) <= 0` 或选中单元集为空，冻结公式无法
  产生全部有限指标；必须中文报错并停止，不能擅自用 `0` 或 `1` 填充分母为零的结果。

`components` 定义为 `unit_graph.json` 中由本围栏 `unit_ids` 诱导出的无向子图连通分量数：
只沿两端都在 `unit_ids` 内的边遍历；不得按几何 union 的类型或环数替代。非空
`unit_ids` 的 `components` 必须为正整数。

门禁判据同时冻结如下，T-203 只产数，T-204 执行门禁：

```python
G2_b_pass = statistics.median(v["iou"] for v in yeidai_values) >= 0.95  # n=17
p2b_triggered = any(v["iou"] < 0.90 for v in dealer_values)             # n=4
```

- G2-c 无预设通过线；必须逐条报告
  `src_id/iou/recall/precision/straddle/components`。
- G2-c 的样本数为 4，禁止报告中位数；任一 `iou < 0.90` 只触发 P2b，不等于
  把 G2-c 记为失败。
- 对标只作参照，不作额外断言：主线全市口径业代中位 `0.970`、经销商中位 `0.764`。

## 输出（相对仓库根；schema 精确）

`data/pilot/oracle_unitsets.json`：

```json
{"method":"3.6-v1.4","link_min_m":50,"boundary_centroids":0,"fences":{"<src_id>":{"name":"围栏名称","layer":"dealer","unit_ids":[0,1,2],"iou":0.97,"recall":0.98,"precision":0.99,"straddle":0,"components":1}}}
```

精确约束：

- 顶层键恰为 `method/link_min_m/boundary_centroids/fences`；`method` 必须等于
  `"3.6-v1.4"`，`link_min_m` 必须等于 `50`。
- `fences` 恰有 21 个键；每项键恰为
  `name/layer/unit_ids/iou/recall/precision/straddle/components`。
- `layer` 只能是 `dealer` 或 `yeidai`，且分别为 4 条和 17 条。
- `iou/recall/precision` 必须是 `[0.0, 1.0]` 内的有限数；`straddle` 和
  `boundary_centroids` 是非负整数；`components` 是正整数。
- 按 `src_id` 确定性排序 `fences`，`unit_ids` 升序；紧凑 UTF-8 JSON、原子替换；
  同一输入双跑字节一致。
- 不增加围栏几何、坐标或 schema 外字段；不得创建第三个数据产物。
