## 输入 schema（全部内联）

P3 上下文与 DSL：

```jsonc
// data/pilot/units.json
{"crs":"GCJ-02","units":[{"uid":0,"key":"源主键","district_code":"440105","street":"街道名","area_km2":1.0,"centroid":[113.0,23.0],"geom":"<Polygon或MultiPolygon WKT>"}]}
// data/pilot/streets.json
{"streets":[{"name":"凤阳街道","code":"440105014","district_code":"440105","geom":"<WKT>"}]}
// data/pilot/districts.json（顶层键仍名为 streets）
{"streets":[{"name":"海珠区","code":"440105","district_code":"440105","geom":"<WKT>"}]}
// data/pilot/unit_graph.json
{"adjacency":{"0":[1],"1":[0]},"link_min_m":50}
```

LLM 配置文件只在用户显式传 `--llm-config <path>` 时读取，MVP schema 精确为：

```json
{
  "provider":"anthropic-compatible",
  "endpoint":"http://127.0.0.1:PORT/v1/messages",
  "model":"MODEL_NAME",
  "api_key_env":"SRAF_LLM_API_KEY",
  "timeout_seconds":30
}
```

- 配置文件路径、endpoint、model 均不得内置默认值；本卡不创建示例配置文件。
- 密钥只从 `api_key_env` 指定的环境变量读取；配置中若出现 `api_key/token/secret`
  等明文凭证字段必须拒绝。密钥、完整请求头和配置原文不得打印。
- `timeout_seconds` 是有限正数且不大于 120；未知 provider 或多/缺字段均中文抛错。

LLM 唯一允许输出的业务对象仍是四原语 DSL：

```jsonc
{"op":"in_street","name":"凤阳街道"}
{"op":"in_district","name":"海珠区"}
{"op":"union","args":[<node>,<node>,...]}
{"op":"minus","args":[<node>,<node>]}
```

`in_street` 是 v1.7 属性判定；禁止 LLM 输出坐标、WKT、uid、面积、components、解释文字、
`side_of` 或 `near`。

## 输出与公共接口（冻结）

在 T-401 接口上增加：

```python
class LlmUnavailableError(Nl2RuleError):
    llm_unavailable = True

class LlmOutputError(Nl2RuleError): ...

# 可插拔边界：测试和未来其他 provider 可注入同签名 callable。
# 返回 Python dict 或“仅含一个 JSON 对象”的 str；不得返回坐标。
LlmAdapter = Callable[[str, dict], object]

def load_llm_config(path: Path) -> dict: ...
def build_llm_prompt(text: str, ctx: dict) -> str: ...
def compile_description(text: str, ctx: dict, llm_adapter=None, llm_config=None) -> dict: ...
def execute_description(text: str, ctx: dict, llm_adapter=None, llm_config=None) -> dict: ...
```

`compile_description` 成功结果顶层键精确为：

```json
{"rule":{"op":"in_street","name":"凤阳街道"},"path":"rule","llm_unavailable":true}
```

- `path` 只允许 `rule` / `llm`。
- `llm_unavailable` 表示本次调用是否没有可用 adapter；规则路径成功时即使为 `true` 也
  不影响成功，但必须证明没有尝试调用 LLM。
- 只捕获 `RuleParseError` 进入 LLM 兜底；输入数据/schema 错误、03 执行错误、代码异常
  不得发送给 LLM 掩盖。

`execute_description` 成功结果顶层键精确为：

```jsonc
{
  "description":"凤阳街道",
  "path":"rule",
  "llm_unavailable":true,
  "rule":{"op":"in_street","name":"凤阳街道"},
  "result":{"unit_ids":[1],"components":1,"area_km2":1.0,"rule":{"op":"in_street","name":"凤阳街道"},"warnings":[]}
}
```

`result` 必须直接来自 `03_dsl.py:execute`，五字段恰为
`unit_ids/components/area_km2/rule/warnings`；不得复制求值逻辑。

## 路由与 LLM 纪律

1. 先调用 `parse_rule_deterministic`。成功即返回，adapter 调用次数必须为 0。
2. 仅当确定性路径抛 `RuleParseError` 时才允许兜底。
3. 无 adapter/config：抛 `LlmUnavailableError`；CLI 输出单行 JSON：
   `{"ok":false,"llm_unavailable":true,"error":"规则路径无法解析且未配置 LLM 兜底"}`
   并以非零退出。
4. 有配置时，默认 adapter 为 anthropic-compatible stdlib `urllib` 实现；未来 provider
   通过注入 `LlmAdapter` 扩展，不得把 HTTP 逻辑耦合进解析器。
5. prompt 只含：原文本、允许的正式街道/区县名、四原语 schema、要求只返 JSON 的纪律。
   prompt 不得含 `units`、uid、centroid、geom、WKT、oracle 答案或任何坐标。
6. adapter 输出必须是一个 JSON 对象。代码围栏、额外解释、多个 JSON、数组、空响应、
   非法 JSON 均拒绝；随后调用 `03_dsl.validate_rule`，再在执行入口调用 `03_dsl.execute`。
7. `validate_rule` 会拒绝坐标字段及 `side_of/near`；不得清洗、删字段后“修好”模型输出。

默认 anthropic-compatible adapter 的线协议也冻结，避免 L2 自行猜测：

```http
POST <config.endpoint>
content-type: application/json
x-api-key: <从 config.api_key_env 对应环境变量读取>
anthropic-version: 2023-06-01
```

```jsonc
// request body
{"model":"<config.model>","max_tokens":1024,"temperature":0,"system":"<固定 DSL 纪律>","messages":[{"role":"user","content":"<prompt>"}]}

// response body（MVP 只接受恰好一个 text block）
{"content":[{"type":"text","text":"{\"op\":\"in_street\",\"name\":\"凤阳街道\"}"}]}
```

HTTP 非 2xx、响应顶层/`content` schema 不符、不是恰好一个 text block、超时均抛中文
`LlmOutputError`（网络尚未产生有效 DSL）或专门的配置/不可用错误；不得自动重试、切换
endpoint 或回退到另一个模型。

## CLI（本卡只实现 translate 子命令）

```bash
python3 sraf-pilot/src/04_nl2rule.py translate \
  --data data/pilot \
  --text "海珠区不含琶洲街道" \
  [--llm-config path/to/private_config.json]
```

- stdout 只输出一个 UTF-8 JSON 对象；成功含 `ok=true` 和上述执行结果。
- stderr/异常不得泄露密钥、请求头、坐标、WKT 或整份配置。
- 规则路径可在不提供 `--llm-config` 时成功。
- 规则失败且未提供配置时必须非零退出并显式 `llm_unavailable=true`。
- 配置路径提供但文件缺失、schema 错、密钥环境变量缺失，也按不可用/配置错误显式失败；
  不得退回空规则或“跳过 LLM”。
