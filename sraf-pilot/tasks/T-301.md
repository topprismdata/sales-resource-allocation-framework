## 目标

建立 P3 的只读输入层、严格 DSL 节点校验和三级名称解析。匹配 0 个或大于 1 个必须
抛中文错误，禁止复刻主线 `lookup_geometry` 的两字前缀兜底，禁止静默取第一个。
本卡不要求完成四原语求值或最终输出汇总。

## 输入（相对仓库根；schema 已内联）

```jsonc
// data/pilot/units.json
{"crs":"GCJ-02","units":[{"uid":0,"key":"源主键","district_code":"440105","street":"街道名","area_km2":1.0,"centroid":[113.0,23.0],"geom":"<Polygon或MultiPolygon WKT>"}]}

// data/pilot/streets.json
{"streets":[{"name":"南石头街道","code":"440105001","district_code":"440105","geom":"<Polygon或MultiPolygon WKT>"}]}

// data/pilot/districts.json（顶层键按既有 P1 契约仍名为 streets）
{"streets":[{"name":"海珠区","code":"440105","district_code":"440105","geom":"<Polygon或MultiPolygon WKT>"}]}

// data/pilot/unit_graph.json
{"adjacency":{"0":[1],"1":[0]},"link_min_m":50}
```

真实数据条件：L1 官方单元 224 个；海珠 `440105` 131 个、荔湾 `440103` 93 个；
40 街道；邻接图 224 节点、538 无向边、`link_min_m=50`、孤立 0。全程 GCJ-02，
不得做坐标转换。几何可能是 MultiPolygon，禁止裸用 `.exterior`。

## CONTRACTS v1.5 冻结块（完整内联；后继语义也不得偏离）

P3-MVP 只允许四个可序列化 JSON 原语，求值结果本体是 `set[int]`：

```jsonc
{"op":"in_street","name":"南石头街道"}
{"op":"in_district","name":"海珠区"}
{"op":"union","args":[<node>,<node>,...]}
{"op":"minus","args":[<node>,<node>]}
```

- `in_street`：严格执行
  `street_geom.contains(Point(unit["centroid"]))`，为真才入选；不用面积重叠。
- `in_district`：单元 `district_code` 等于解析后的区编码；只用属性，不做几何判定。
- `union`：所有子节点结果集的并。
- `minus`：严格为 `eval(args[0]) - eval(args[1])`。
- `side_of` / `near` 属 P3b，本轮不得实现或接受。
- 名称解析按“精确 → 去末尾后缀（街道/镇/区）→ 包含匹配”逐级进行；在某一级
  得到唯一匹配即返回。匹配 0 个或大于 1 个一律抛错，不得静默取第一个，不得使用
  两字前缀兜底。街道只在街道表内解析，区县只在区县表内解析。

最终执行输出 schema 必须恰为：

```json
{"unit_ids":[12,13],"components":1,"area_km2":3.2,"rule":{"op":"in_street","name":"南石头街道"},"warnings":[]}
```

其中 `unit_ids` 升序唯一；`components` 必须在 L1 官方单元层用
`data/pilot/unit_graph.json` 计算，L2 细面不得参与；`rule` 原样回填且不得被修改；
`warnings` 必须是字符串数组。名称 0 匹配是异常，禁止降级为 warning 后返回空集。

G3 必含七类退化用例，后继 T-304 缺一不可：

1. 空结果：街道名不存在必须抛错，不返回空集；
2. 单单元结果；
3. `minus` 结果为空集；
4. `union` 含重复子树时幂等；
5. 多分量结果，`components >= 2`；
6. 名称包含匹配大于 1 个时抛错；
7. 嵌套至少 3 层的树。

G3 通过线只有 100%：给定人工写好的 oracle DSL 树，实际单元集必须与**独立来源**的
期望单元集完全相等；不得由被测执行器或其内部 helper 反算 expected。

## 本卡输出与实现纪律

模块至少提供可单测的：输入加载/schema 校验、DSL 节点结构校验、街道名称解析、区县
名称解析。严格校验各 op 的字段和 arity：叶节点只能有 `op/name`；`union.args` 至少
包含 2 个节点；`minus.args` 恰有 2 项；未知 op、额外字段、缺字段、非对象节点均中文抛错。

- Python 3.11+；路径用 `pathlib.Path`；JSON UTF-8；输入只读；不访问网络。
- 几何只接受非空 Polygon/MultiPolygon；不得重写输入或产生新数据文件。
- 不修改传入的 DSL、units、streets、districts 或 graph 对象（immutable）。
- 错误消息含输入路径或 DSL 节点位置及中文原因。
- 不得修改冻结文档、JOURNAL、state，不得 commit/push，不得调用 omp。

## 可执行验收断言

`sraf-pilot/tests/test_03_dsl.py` 用 `unittest` 和临时目录，至少断言：

```python
assert payload["crs"] == "GCJ-02"
assert [u["uid"] for u in units] == list(range(len(units)))
assert all(g.geom_type in {"Polygon", "MultiPolygon"} and not g.is_empty for g in unit_geoms)
assert resolve_street("彩虹街道").name == "彩虹街道"       # 精确
assert resolve_street("彩虹").name == "彩虹街道"           # 去后缀
assert resolve_district("海珠").code == "440105"           # 去“区”后缀
assert json.dumps(rule, sort_keys=True) == rule_bytes_before  # 不修改输入树
```

合成名称表必须逐级证明：精确匹配优先于后续模糊阶段；去后缀唯一匹配成功；包含唯一匹配
成功；0 匹配抛错；包含匹配 2 个以上抛错。歧义夹具可用 `人民街道` 与 `人民镇`，查询
`人民` 必须抛错。还必须断言两字前缀不会被当作独立兜底规则。

非法节点必须逐类抛错：空对象、未知 op、`side_of`、`near`、叶节点缺/多字段、
`union.args` 少于两项、`minus` 非两参、args 含非对象。MultiPolygon 夹具证明没有使用
`.exterior`。所有失败均不得写文件。

运行：

