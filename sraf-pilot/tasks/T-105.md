# T-105 — P1 集成验收与 G1 证据包

## 状态与依赖

- 阶段：P1
- 依赖：T-101 → T-102/T-103 → T-104 全部完成；G0 经 L0 签字。
- 解冻裁定：P1/G1 只考核 7 个文件；`unit_graph.json` 与 `oracle_unitsets.json`
  明确归 P2 的 `02_units.py`，本卡必须断言二者不存在，不得创建空壳。
- 施工范围：只允许整理/修正 `sraf-pilot/src/01_extract.py` 与 `sraf-pilot/tests/test_01_extract.py`；本卡不得新建第二个实现模块。

## 目标

端到端运行 `01_extract.py`，验证 P1 已获批准的全部输出 schema、确定性、源数据只读性、
坐标数字证据和脏点留档，形成 G1 可供 L1 复核的原始输出。L2 不得自行宣布 Phase 结束，
G1 与 Phase 收尾仍需 L1 跑门禁并由 L0 人工签字。

## 输入（相对仓库根）

- `sraf-pilot/src/01_extract.py`
- `sraf-pilot/tests/test_01_extract.py`
- `<SRC_DIR>` 下 T-101 内联的五个客户源文件（只读）
- 本卡内联的冻结规则：街道以 `父级id == 区县.区域编码` 精确连接并应为 40 个；
  围栏以 `overlap_ratio >= 0.5` 入选并输出比值，`src_id` 为 `片区id` 原值且禁止按名
  去重，应为经销商 4 条、业代 17 条；CRS 证据按 §3.5.4 固定方法且必须判
  `SAME_CRS_GCJ02`。

## 输出（相对仓库根）

P1 唯一获批的 7 个输出：

```text
data/pilot/units.json
data/pilot/streets.json
data/pilot/districts.json
data/pilot/fences_dealer.json
data/pilot/fences_yeidai.json
data/pilot/crs_evidence.json
data/pilot/data_issues.md
```

JSON schema 必须分别等于：

```json
{"crs":"GCJ-02","units":[{"uid":0,"key":"str","district_code":"440105","street":"str","area_km2":1.0,"centroid":[113.0,23.0],"geom":"<WKT>"}]}
{"streets":[{"name":"str","code":"str","district_code":"440105","geom":"<WKT>"}]}
{"fences":[{"name":"str","src_id":"str","area_km2":1.0,"center":[113.0,23.0],"overlap_ratio":0.999,"geom":"<WKT>"}]}
{"method":"3.5.4","n_fences":4,"vertex_cap":200,"median_A_m":0.0,"median_B_m":0.0,"verdict":"SAME_CRS_GCJ02","per_fence":[{"src_id":"str","name":"str","n_vertices":200,"median_A_m":0.0,"median_B_m":0.0}]}
```

P2 才允许生成的两个文件：

```text
data/pilot/unit_graph.json
schema = {"adjacency":{"<uid>":[uid,...]},"link_min_m":50}

data/pilot/oracle_unitsets.json
schema = {"<src_id>":{"unit_ids":[int,...],"coverage":float,"straddle":int}}
```

本卡不得实现邻接或 oracle，也不得创建空壳文件骗过文件存在断言。

## 可执行验收断言

先运行：

```bash
python3 -m unittest discover sraf-pilot/tests -q
python3 sraf-pilot/src/01_extract.py --src <SRC_DIR> --out data/pilot
```

必须满足：

```python
assert unittest_exit_code == 0
assert extract_exit_code == 0
assert set(unit_district_codes) == {"440105", "440103"}
assert unit_uids == list(range(len(unit_uids)))
assert len(unit_keys) == len(set(unit_keys))
assert len(units) > 0 and len(streets) > 0 and len(districts) == 2
assert len(streets) == 40
assert len(dealer_fences) == 4 and len(yeidai_fences) == 17
assert all(0.5 <= f["overlap_ratio"] <= 1.0 for f in dealer_fences + yeidai_fences)
assert all_output_geometries_parse_and_are_nonempty is True
assert data_issues_contains_all_three_known_duplicate_names is True
assert crs_evidence["method"] == "3.5.4"
assert crs_evidence["n_fences"] == 4 and crs_evidence["vertex_cap"] == 200
assert crs_evidence["median_A_m"] < 100 and crs_evidence["median_B_m"] > 300
assert crs_evidence["verdict"] == "SAME_CRS_GCJ02"
assert source_hashes_before == source_hashes_after
assert rerun_output_hashes_first == rerun_output_hashes_second
```

还必须明确断言 `data/pilot/unit_graph.json` 与 `data/pilot/oracle_unitsets.json`
均不存在，并在 G1 记录注明“P2 待产出”。为避免历史残留造成假失败，运行前如发现二者
已存在不得删除，应输出 `ESCALATION:<历史 P2 产物存在>` 并停止交由 L1 处理。

任何断言失败都必须保留原始关键行并在 JOURNAL 追加 `[GATE-FAIL]`；不得悄悄重跑后只报成功。
真实数量和坐标数字不得硬编码到测试。
