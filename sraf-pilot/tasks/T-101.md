## 目标

为后续抽取建立一个确定性的 CLI 和只读输入层。只做文件定位、字段校验、
GeoJSON/CSV/WKT 安全读取与错误处理；本卡不决定围栏筛区、重复名取舍、坐标系结论，
也不产出 `unit_graph.json` 或 `oracle_unitsets.json`。

## 输入（相对仓库根）

CLI 形态必须是：

```bash
python3 sraf-pilot/src/01_extract.py --src <SRC_DIR> --out data/pilot
```

`--src` 必须由调用者显式传入，代码中禁止出现 `/Users/...` 等绝对路径默认值。
从 `<SRC_DIR>` 只读以下文件：

| 逻辑名 | 文件名 | 必需字段 |
|---|---|---|
| `UNITS_SRC` | `边界数据-路网-到区县带海岸线-四级路网-广东省-广州市.geojson` | `区县编码`、`街道[内置]`、`中心点`、`面积`、`主键` |
| `STREETS_SRC` | `区划数据-街道-广东省-广州市.geojson` | `行政区名称`、`区域编码`、`父级id` |
| `DISTRICTS_SRC` | `区划数据-区县-广东省-广州市.geojson` | `行政区名称`、`区域编码` |
| `DEALER_SRC` | `广州办事处经销商围栏数据-20260827.csv` | `围栏名称`、`fence`、`中心点经度`、`中心点纬度`、`围栏面积` |
| `YEIDAI_SRC` | `广州清单内业代的围栏数据-20260824.csv` | 上一行全部字段，另加 `办事处名称` |

GeoJSON 输入结构按标准 FeatureCollection 读取：

```json
{"type":"FeatureCollection","features":[{"type":"Feature","properties":{},"geometry":{}}]}
```

CSV 必须以 `utf-8-sig` 编码读取，并在读取前执行：

```python
csv.field_size_limit(sys.maxsize)
```

`fence` 是 WKT，使用 `shapely.wkt.loads` 解析；几何不得为空。

不得写入 `<SRC_DIR>`，不得修改 `sraf-pilot/CONTRACTS.md`、`00_BRIEF.md`、

## 实现纪律（已内联）

- Python 3.11+；路径使用 `pathlib.Path`。
- 注释和 docstring 用中文；面向业务用户的错误信息用中文。
- 客户源文件只读；不把 CSV、GeoJSON 或生成数据加入 git。
- 缺文件、非 FeatureCollection、缺字段、非法数字、空/非法 WKT 必须抛出带文件名和字段名的中文异常；不得跳过坏行后继续。
- 不得执行 git commit、push 或 force-push。

## 可执行验收断言

在 `sraf-pilot/tests/test_01_extract.py` 中用临时目录和最小合成夹具覆盖：

```python
assert cli_requires_explicit_src is True
assert cli_accepts_explicit_out is True
assert source_bytes_before == source_bytes_after
assert parsed_geojson["type"] == "FeatureCollection"
assert len(parsed_geojson["features"]) == expected_feature_count
assert parsed_csv_row["围栏名称"] == expected_name
assert len(parsed_csv_row["fence"]) > 131_072  # 证明超长字段未被默认上限截断
assert parsed_wkt.is_empty is False
```

并逐项断言以下输入会抛异常，且 `str(error)` 同时包含中文原因、文件名、缺失/错误字段名：

1. 五个源文件中任一缺失；
2. GeoJSON 顶层不是 `FeatureCollection`；
3. 任一必需字段缺失；
4. CSV 中心点或面积不是数字；
5. `fence` 是空串或非法 WKT。

运行：

```bash
python3 -m unittest sraf-pilot/tests/test_01_extract.py -q
```

预期：退出码 `0`，无网络访问，无客户目录写入。
