## 目标

按冻结常数 `LINK_MIN_M = 50` 建立全部试点单元的无向邻接图，并执行 G2-a：
总的两两重叠面积占全部单元面积小于 0.1%，且无孤立单元。真实飞地不得由 L2 自行豁免；
若出现孤立单元，列出其 `uid/key/district_code/street` 后上报并停止。

## 输入（相对仓库根；schema 已内联）

`data/pilot/units.json`：

```json
{"crs":"GCJ-02","units":[{"uid":0,"key":"源主键","district_code":"440105","street":"街道名","area_km2":1.0,"centroid":[113.0,23.0],"geom":"<Polygon或MultiPolygon WKT>"}]}
```

冻结事实与判定：

```python
LINK_MIN_M = 50
uid == units数组下标
```

两单元的共享边界长度 **大于或等于 50 米** 才邻接；仅点接触、共享长度不足 50 米、
相离或只有面积重叠均不得建立边。全程保持 GCJ-02，不调用 `gcj2wgs`。

共享边界米数的可执行算法：计算 `a.boundary.intersection(b.boundary)`，递归收集其中
LineString/LinearRing/MultiLineString/GeometryCollection 的线性部分，对每段相邻坐标调用
仓库既有 `intelligence.world.haversine_km(p, q) * 1000` 后求和；Point/MultiPoint
贡献为 0。禁止用经纬度坐标的 `.length` 直接冒充米。

G2-a 重叠率按全部无序单元对计算：

```python
pair_overlap_ratio = sum(a.intersection(b).area for i < j) / sum(u.area for u in unit_geoms)
assert pair_overlap_ratio < 0.001
```

分子分母均使用同一批 GCJ-02 几何的 Shapely 平面面积，比例为无量纲；不得用门店或围栏
位置验证单元几何。

## 输出（相对仓库根）

`data/pilot/unit_graph.json` schema 精确为：

```json
{"adjacency":{"0":[1,2],"1":[0],"2":[0]},"link_min_m":50}
```

约束：

- `adjacency` 必须包含每个 uid 的字符串键，包括可能的孤立节点；值为升序、唯一整数数组。
- 无自环；对称：`v in adjacency[str(u)]` 当且仅当 `u in adjacency[str(v)]`。
- 按 uid 升序写键，紧凑 UTF-8 JSON，原子替换；同一输入双跑字节一致。
- 不得加入 schema 外的诊断字段。G2-a 的重叠率和孤立清单只打印精简汇总并交 L1 留痕。
- 本卡不得创建 `oracle_unitsets.json`。

## 可执行验收断言

单测至少构造：共享 50m、49.999m、仅点接触、相离、Polygon-MultiPolygon、
GeometryCollection 共享线等最小夹具，并断言：

```python
assert graph["link_min_m"] == 50

```

真实数据验收还必须满足：

