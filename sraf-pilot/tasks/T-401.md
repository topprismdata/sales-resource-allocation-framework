## 目标

全过程不调用 LLM、不处理坐标、不自行求值单元。解析成功后必须复用

只允许输出下列 v1.7 四原语：

```jsonc
{"op":"in_street","name":"凤阳街道"}
{"op":"in_district","name":"海珠区"}
{"op":"union","args":[<node>,<node>,...]}
{"op":"minus","args":[<node>,<node>]}
```

`in_street` 在后续执行时按单元 `street` 属性精确相等判定；街道几何不参与单元选取。
`in_district` 按 `district_code` 属性判定。禁止输出 `side_of`、`near`、经纬度、WKT、
单元 id 或五字段执行结果。

## 冻结语法（不得自行扩展）

先去除首尾空白；允许全角/半角逗号作为模板标点。只接受以下形式：

```text
ATOM
ATOM (和|、|加上|以及) ATOM [...]
BASE 不含 EXCLUSION_LIST
BASE 除 EXCLUSION_LIST 外
除 EXCLUSION_LIST 外，BASE
```

- `ATOM`：一个且仅一个街道名或区县名。允许正式全名或 `03_dsl.py` 三级名称解析可
  唯一解析的简称；必须规范化回填正式名。
- `BASE`、`EXCLUSION_LIST`：分别是 `ATOM` 或只含上述并集连接词的 ATOM 列表。
- 可在整个表达式外使用一次无业务含义包装：前缀 `范围为/覆盖/包括/选择/负责`，后缀
  `范围/区域/片区`。去包装后仍须完整匹配冻结语法；未知残余文字不得忽略。
- 并集规范化为单个扁平 `union`；保持文本顺序；相同规范节点按首次出现去重。去重后
  只剩一个节点则直接返回该节点，不生成非法单参 union。
- `A不含B`、`A除B外`、`除B外，A` 都规范化为
  `{"op":"minus","args":[parse(A),parse(B)]}`。
- 一条文本出现多个差集标记、差集嵌套、括号改变优先级、连接词两侧缺项、同一 ATOM
  同时可解析为街道和区县、名称 0 匹配或歧义，均抛 `RuleParseError`，不得猜测。
- 空字符串、非字符串、纯标点也抛 `RuleParseError`。

解析成功后调用 `03_dsl.py:validate_rule(rule)`；不得复制、改写或放宽 03 的校验器。
由于文件名以数字开头，可用 `importlib.util.spec_from_file_location` 按相邻文件路径加载，
不得写死绝对路径。

## 硬纪律

- D12：本卡是确定性规则路径，任何测试和生产分支都不得发起网络请求或调用 LLM。
- 不扫描或抽取坐标；不读取 `geom/centroid` 来决定 DSL；不做几何计算。
- 不修改输入 `text`、`ctx`、街道/区县行或返回后被调用方持有的对象。
- 未完整消费文本必须失败；禁止“识别到几个名字就忽略其余文字”。
- 中文错误至少含原文本和失败原因；不得静默返回空树、空集或 `None`。
- 串行执行；不访问网络；不创建数据或报告文件；不调用其他 Agent。
- 不修改冻结文档、JOURNAL、state；不得 commit/push。
