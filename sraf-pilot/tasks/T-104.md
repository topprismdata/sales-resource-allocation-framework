# T-104 — P1 坐标系数字验证

## 状态与依赖

- 阶段：P1
- 依赖：T-102、T-103 完成；G0 经 L0 签字。
- 后继：T-105。
- 当前冻结点：契约要求数字验证，但没有冻结顶点抽样、米制距离算法、混合坐标对照方式、显著性阈值与证据落盘位置。L0 回复前不得派发本卡。
- 施工范围：只允许增量修改 `sraf-pilot/src/01_extract.py` 与 `sraf-pilot/tests/test_01_extract.py`。

## 目标

用数字证据验证客户经销商围栏与官方单元边界是否同为 GCJ-02。必须分别得到“GCJ 原坐标直比”
与“按 L0 确认方式转 WGS 后混合对比”的最近距离中位数，不能以“客户 CRM 应该是高德系”代替测量。

## 输入（相对仓库根）

- `data/pilot/units.json`

```json
{"crs":"GCJ-02","units":[{"uid":0,"key":"...","district_code":"440105","street":"...","area_km2":1.0,"centroid":[113.0,23.0],"geom":"<WKT>"}]}
```

- `data/pilot/fences_dealer.json`

```json
{"fences":[{"name":"...","src_id":"...","area_km2":1.0,"center":[113.0,23.0],"geom":"<WKT>"}]}
```

- 坐标转换只能复用 `intelligence/coords.py`；不得另写 GCJ/WGS 转换公式。

L0 必须先把以下五项补成精确值：

1. 使用全部顶点还是确定性采样；若采样，样本数与种子；
2. 最近距离的参考边界集合，以及围栏顶点与单元边界的配对/搜索范围；
3. 经纬度到米的计算/投影方法；
4. 哪一侧数据转换为 WGS，另一侧是否保持 GCJ；
5. “显著小于约 623 m”的可执行阈值，以及证据写入 `data_issues.md` 还是新增获批产物。

## 输出

不允许自行新增未在契约中定义的 JSON schema。获 L0 确认后，至少要持久化并在 CLI 输出同一组数字：

```text
样本顶点数 N
GCJ 原坐标直比最近距离中位数 median_gcj_m
转 WGS 后混合对比最近距离中位数 median_mixed_m
两者差值 delta_m
两者比值 ratio
判定 PASS/FAIL
```

最终数据文件仍声明：

```json
{"crs":"GCJ-02"}
```

试点内部不得转换并覆写 `units.json` 或 fence JSON 的几何。

## 可执行验收断言

L0 冻结算法与阈值后，单测必须包含可控平移的合成几何并断言：

```python
assert sample_count == approved_expected_count
assert math.isfinite(median_gcj_m) and median_gcj_m >= 0
assert math.isfinite(median_mixed_m) and median_mixed_m >= 0
assert delta_m == pytest_free_approved_formula  # 用 unittest/assertAlmostEqual 实现，不引 pytest
assert ratio == pytest_free_approved_formula
assert coordinate_verdict in {"PASS", "FAIL"}
assert units_payload["crs"] == "GCJ-02"
```

其中阈值断言必须写成 L0 批准的明确比较式，禁止写 `assert significantly_smaller`、
禁止只检查数字非空。测试框架只能用 `unittest`。

真实数据运行还必须满足：

- CLI 退出码为 `0` 才可判 G1 坐标子项通过；若数字不满足阈值，必须退出非零并按 `[GATE-FAIL]` 留档。
- 同一输入连续运行两次，样本数、两个中位数、差值、比值和判定一致。
- 日志不得打印完整客户 WKT、客户名单或任何凭证。

运行：

```bash
python3 -m unittest sraf-pilot/tests/test_01_extract.py -q
python3 sraf-pilot/src/01_extract.py --src <SRC_DIR> --out data/pilot
```
