# T-102 — P1 官方单元、区县与街道抽取

## 状态与依赖

- 阶段：P1
- 依赖：T-101 完成；G0 经 L0 签字。
- 后继：T-104、T-105。
- 解冻裁定：`街道.父级id == 区县.区域编码`，必须精确等值匹配；海珠 18 个、
  荔湾 22 个，合计 40 个街道。任何街道 `父级id` 不在完整区县编码集合中必须抛错，
  禁止模糊/名称/空间匹配或静默跳过。
- 施工范围：只允许增量修改 `sraf-pilot/src/01_extract.py` 与 `sraf-pilot/tests/test_01_extract.py`。

## 目标

从官方 GeoJSON 中抽取海珠区 `440105` 与荔湾区 `440103` 的单元、区县和街道，
确定性写出三个 GCJ-02 中间产物。不得做坐标转换，不得用门店位置验证几何。

## 输入（相对仓库根）

由 `--src <SRC_DIR>` 指向：

1. `<SRC_DIR>/边界数据-路网-到区县带海岸线-四级路网-广东省-广州市.geojson`
   - 属性：`区县编码`、`街道[内置]`、`中心点`、`面积`、`主键`
   - 几何：GeoJSON Polygon 或 MultiPolygon
2. `<SRC_DIR>/区划数据-街道-广东省-广州市.geojson`
   - 属性：`行政区名称`、`区域编码`、`父级id`
   - 几何：GeoJSON Polygon 或 MultiPolygon
3. `<SRC_DIR>/区划数据-区县-广东省-广州市.geojson`
   - 属性：`行政区名称`、`区域编码`
   - 几何：GeoJSON Polygon 或 MultiPolygon

冻结筛选集必须是：

```python
PILOT_DISTRICT_CODES = {"440105", "440103"}
```

单元按属性 `区县编码` 精确筛选；区县按属性 `区域编码` 精确筛选。
街道按 `父级id == 区县.区域编码` 精确等值连接。读取完整街道、区县源后，先验证每条街道
的 `父级id` 都存在于完整区县 `区域编码` 集合，再筛选父级为 `440105` 或 `440103` 的街道；
禁止包含匹配、两字前缀、名称匹配、空间相交或静默取第一条。真实输出必须恰好包含海珠
18 个、荔湾 22 个街道，合计 40 个。

## 输出（相对仓库根）

由 `--out data/pilot` 写出：

`data/pilot/units.json`

```json
{"crs":"GCJ-02","units":[{"uid":0,"key":"源主键","district_code":"440105","street":"源街道值","area_km2":1.0,"centroid":[113.0,23.0],"geom":"<WKT>"}]}
```

`data/pilot/districts.json`

```json
{"streets":[{"name":"海珠区","code":"440105","district_code":"440105","geom":"<WKT>"}]}
```

`data/pilot/streets.json`

```json
{"streets":[{"name":"某街道","code":"区域编码","district_code":"440105","geom":"<WKT>"}]}
```

说明：`districts.json` 必须沿用契约规定的同一顶层键 `streets`，不得擅自改成
`districts`。所有 WKT 必须由源 GeoJSON 几何无损转写；不得 union/difference 或简化。
`uid` 在本次输出内等于 `units` 数组下标，排序必须确定性；不得把 `key` 作为 `uid`。

## 可执行验收断言

使用最小合成夹具写单测，并在获准后对真实输出执行同样断言：

```python
assert payload["crs"] == "GCJ-02"
assert len(units) > 0
assert [u["uid"] for u in units] == list(range(len(units)))
assert len({u["key"] for u in units}) == len(units)
assert {u["district_code"] for u in units} == {"440105", "440103"}
assert set(units[0]) == {"uid","key","district_code","street","area_km2","centroid","geom"}
assert all(isinstance(u["uid"], int) for u in units)
assert all(isinstance(u["key"], str) and u["key"] for u in units)
assert all(isinstance(u["area_km2"], float) and u["area_km2"] > 0 for u in units)
assert all(len(u["centroid"]) == 2 for u in units)
assert all(wkt.loads(u["geom"]).is_empty is False for u in units)
assert {d["code"] for d in districts["streets"]} == {"440105", "440103"}
assert {d["district_code"] for d in districts["streets"]} == {"440105", "440103"}
assert all(s["district_code"] in {"440105", "440103"} for s in streets["streets"])
assert all(set(s) == {"name","code","district_code","geom"} for s in streets["streets"])
assert len(streets["streets"]) == 40
assert sum(s["district_code"] == "440105" for s in streets["streets"]) == 18
assert sum(s["district_code"] == "440103" for s in streets["streets"]) == 22
```

额外断言：

- 输入夹具混入第三个区县后，三个输出中都不得出现第三个区县编码。
- 同一输入连续运行两次，三个输出文件字节完全相同。
- 源几何为空/非法、`key` 重复、区县缺任一目标编码、任一街道 `父级id` 不在完整区县
  `区域编码` 集合、街道无法唯一连接父区县时必须中文报错并退出非零；不得生成半成品文件。
- 真实源文件总单元数 `2,675` 只能作为输入完整性检查；试点单元数不得硬编码，实际数需写 JOURNAL。
