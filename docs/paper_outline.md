# TerritoryIR: 基于布尔表示的双向区域描述系统

## 1. 引言
### 1.1 问题
- 中国快消品经销商的区域管理：总部画围栏 → 业代执行
- 围栏是几何多边形，但日常沟通需要自然语言描述
- 现有方案：手工写描述（不可靠）、LLM 直接生成（不可控）
- 需求：双向——围栏→描述（编译），描述→围栏（重演）

### 1.2 挑战
- 中国城市数据特殊性：GCJ-02/WGS-84 跨坐标系、四级路网不满铺
- 路网地块颗粒度粗（2675 个父地块），围栏边界切割地块
- 水域带/街道界带无地块可贴
- 人类语言与机器精度之间的鸿沟

### 1.3 贡献
- TerritoryIR：基于双铺盖布尔代数的区域描述中间表示
- 双向管线：IR 编译 + 双投影（人话 verbalize / 引擎 serialize）
- 闭环验证：parse(verbalize(IR)) ≡ IR
- 43 个区域（32 经销商 + 11 业代）的实验验证

## 2. 相关工作
### 2.1 空间区域描述
- RCC-8（Randell, Cui & Cohn, 1992）——定性空间关系
- RCC 布尔组合（Wolter & Zakharyaschev, 2000）——补运算
- COSIT 系列——人类空间认知

### 2.2 自然语言生成
- REG 增量算法（Dale & Reiter, 1995）
- 否定/例外式表达（van Deemter, 2002）
- D2T NLG 管线（Gatt & Krahmer, 2018）

### 2.3 地籍与空间数据
- ISO 19152 LADM——地籍领域模型（LA_SpatialUnit, LA_BAUnit）
- GeoSPARQL——OGC 空间语义标准
- 中国四级路网数据——高德 AMap 路网切块

### 2.4 现存差距
- 已有工作做**区域优化**（聚类、路线），不做**描述已存在区域**
- 已有工作做**几何→语言**或**语言→几何**，不做**双向闭环**
- 已有工作用**单一铺盖**，不做**双铺盖布尔组合**+剩余带

## 3. 方法论
### 3.1 数据准备
- 四级路网地块（2675 个父地块，GCJ-02）
- 行政街道铺盖（228 个街道面，GCJ-02）
- OSM 道路/河涌（WGS-84，特征匹配时 gcj2wgs 转换）
- 手绘围栏（WGS-84，需 wgs2gcj 转 GCJ 后与地块同帧）

### 3.2 统一铺盖 U
- 地块按街道面切割，每片带二元属性 (B街, A街)
- 6261 片，保证每片属于唯一街道和唯一地块
- 街道剩余带 R = A 街面 − ∪{U 片 ∈ A 街}

### 3.3 特征索引
- 线性地物（路+河统一）：每个地块片 100m 内贴附的地物名
- 地物显著性等级（路：高速0/主干2/次干3/… 河：3）
- 5.9 万条地物线段，1.3 万个命名地物

### 3.4 IR 架构
#### 3.4.1 SIR（语义中间表示）
五类子句，均为 U 或 R 上的确定性布尔表达式：
- `block`：B街 = 名 → 该街道所有地块片
- `feat`：B街 = 名 ∩ 贴附地物 F → 沿路/沿河片
- `slice`：B街 = 名 ∩ A街 = 名 → 街道跨界片
- `except`：A区 − 排除街 → 全域补集
- `band`：A街 − U片 → 街道剩余带（RCC 补运算）
- `pieces`：P#k → 单个原子片（兜底）

#### 3.4.2 合成（围栏 → SIR）
- 真值 T = {U 片 | 片重叠 ≥50% 围栏面积 或 重叠 ≥30% 围栏面积}
- 贪心最小覆盖：从全局词表中选 (词, 子句) 对，min(过选) → max(覆盖)
- P# 原子保证 J=1.0 完备性
- 界带子句：围栏 − 片并集，沿行政界/河涌的剩余段

#### 3.4.3 正向投影（verbalize）
- 按 (B街, 子句类型) 聚合，每街 ≤1 句
- REG 偏好序：地物显著性等级优先
- 街道数 >4 → 区级补集/方位概要（"增城区除正果镇、小楼镇外"）
- 界带附加方位前缀（"西至龙洞街道—长兴街道界"）

#### 3.4.4 反向投影（parse）
- 确定性语法：人话短语 → SIR 子句（类型、街道、地物、排除集）
- LLM 润色后 parse-equivalence 校验（`parse(verbalize(IR)) ≡ IR`）
- 失败回退确定性模板

### 3.5 评估指标
- 地块级 J：hit/(hit+over+miss)，真值 vs 引擎片
- 几何级 IoU：围栏 vs 重建多边形
- 覆盖：围栏被重建覆盖的面积百分比
- 人话可读性：词数、句数、主观评价

## 4. 实验
### 4.1 数据集
- 经销商围栏：32 个，广州，面积 0.6–2010 km²
- 业代区域：11 个，海珠/荔湾
- 街道面：228 个
- 四级路网地块：2675 个父 → 6261 个切割片

### 4.2 实验结果
#### 4.2.1 正向（描述质量）
| 指标 | 经销商(32) | 业代(11) |
|---|---|---|
| J 中位 | 1.000 | 1.000 |
| J=1.0 比例 | 32/32 | 10/11 |
| IoU 中位 | 0.992 | 0.971 |
| 覆盖中位 | 99.81% | 99.17% |
| 人话句数 | 5–51 句 | 2–10 句 |

#### 4.2.2 反向（重演质量）
- 所有 43 个区域正向→反向→正向闭环通过
- `parse(verbalize(IR)) ≡ IR` 对全部确定性模板成立
- LLM 润色后等价校验通过率待测

#### 4.2.3 坐标系统一的影响
| 配置 | 浩盛 IoU |
|---|---|
| 围栏 WGS + 地块 GCJ（错位） | 0.696 |
| 围栏 GCJ + 地块 GCJ（对齐） | 0.990 |

### 4.3 案例分析
- 亨啡源北区（街道密集型）：J=1.00, IoU=0.997, 人话6句
- 浩盛（水域带型）：J=1.00, IoU=0.990, 人话5句 + 界带3句
- 宏历（郊区大型）：J=1.00, IoU=0.999, 人话13句（概要模式）
- 郑铭（微型围栏）：J=1.00, IoU=0.094, 人话2句

## 5. 讨论
### 5.1 局限性
- 四级路网不满铺：水域带、河涌带无地块 → 覆盖天花板
- 微型围栏（<1 km²）：IoU 受地块粒度限制
- 郊区大型经销商：人话句数偏多（概要模式已缓解）
- 河涌带词汇尚未自动化纳入地物索引

### 5.2 未来工作
- 水体带自动纳入地物索引（river_buffer − U 片）
- 多级概要（区→街道→路→界，逐层展开）
- LLM 润色等价校验的自动化
- 其他城市/国家的泛化

## 6. 结论
- TerritoryIR：基于双铺盖布尔代数的区域描述表示
- 双向管线：编译→双投影，闭环验证
- 43 个区域：J=1.0（42/43），IoU 中位 0.99
- 首次将 RCC 布尔组合、REG 增量算法、中国四级路网、业代/经销商区域统一在一个系统中
