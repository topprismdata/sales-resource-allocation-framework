# 围栏描述本体 v3（文献接地版）

## 文献基础

| 来源 | 核心结论 | 在本体的落点 |
|---|---|---|
| RCC-8 / 空间逻辑 | 区域描述词 = 命名区域上的布尔组合（∪/∩/补），语义确定、与上下文无关 | 四类词全部定义为铺盖原子上的确定布尔式 |
| 地籍测绘（sliver/residual） | 铺盖必须"无缝无叠"；持续剩余带归属命名单元 | 界带词 = 街道面 − 地块并集（剩余带归属） |
| REG 增量算法（Dale & Reiter 1995） | 属性偏好序；适度冗余=人类自然；多项式复杂度 | 路词按道路等级偏好序（高速>主干>次干） |
| REG 否定/例外研究 | "除X外"在例外集小且显著时是自然表达；例外多时认知负荷反增 | 补集式仅在 例外≤3 且 区覆盖率≥60% 时启用 |
| D2T NLG 管线 | content determination + salience 决定"说什么" | 街道按围栏内面积降序；只说覆盖最多的路 |
| COSIT 人类空间描述 | 层级锚定（大区→地标）；日常语言中的区域词是模糊区域 | 概要/明细两级；界带词给模糊短语一个确定外延 |

## 基础铺盖

- **B（地块铺盖）**：四级路网地块，2675 父 → 按街道面切为 6261 片。有孔（水域带、街道界带不满铺）
- **A（街道铺盖）**：228 个行政街道面，法定无缝

## 词法（四+一类，每词 = 确定布尔式，与围栏无关）

| 词型 | 例 | 布尔式 |
|---|---|---|
| 块词 | `凤凰街道` | ∪{B片: 街=X} |
| 路词 | `龙洞街道沿华南快速` | {B片: 街=X} ∩ road_buffer(100m) |
| 片词 | `凤凰街道(限龙洞街道内)` | {B片: 街=X} ∩ A原子(street=Y) |
| 界带词 | `龙洞街道界带` | A原子(Y) − {B片: 街=Y}（剩余带） |
| 水带词(待实现) | `后航道河岸带` | river_buffer(150m) − B原子（水域无地块带） |

## 句法（人类组合规则）

1. **层级锚定**：区县 → 方位 → 街镇 → 路辐射（概要句→明细句两级）
2. **显著性排序**：道路等级、街道面积降序
3. **例外式**：区覆盖率≥60% 且 例外街镇≤3 → "X区除Y、Z街道外"
4. **模糊容忍**：人话是蛋黄-蛋白式模糊区域；引擎层给出确定外延

## 评估双层

- 引擎层：地块 J = hit/(hit+over+miss)，目标 1.0
- 人话层：围栏覆盖率 + IoU（受手绘抖动与粒度天花板限制，非方法缺陷）
