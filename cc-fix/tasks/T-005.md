# T-005 消除静默降级（Phase 3）

规格来源：`cc-fix/CONTRACTS.md`（**只读**）。本卡已内联全部所需信息。

## 目标

`/api/generate` 当前在回放失败时**静默降级并伪装成功**。必须让降级**显式可见**。

这是审查认定的最危险问题：**崩溃至少诚实，伪装成功不诚实。**

## 现状（`tools/demo_server.py`，已实测，行号为当前值）

```python
# 791  首选：TerritoryIR 编译结果
tcf = pack["data_dir"] / "territory_compiled.json"
trows = json.loads(tcf.read_text(...)) if tcf.exists() else []

if hit and hit.get("S"):
```

**问题**：两条路径返回**同一个 `interpretation` 值**。唯一差别藏在
`lines_used.allocator` 子字段（`replay` vs `compiler`），前端并未据此区分展示；
失败原因只 `print` 到服务端控制台，调用方完全看不到。

据 RC1.0 提交信息自述，台账重演路径的 **IoU 为 0.0–0.14**，
而回放路径为 **0.95–1.0**。二者质量相差一个数量级，却对外呈现为同一状态。

## 实现要求

### 1. 四条路径返回诚实且互不相同的标识

| 路径 | `interpretation` | `confidence` | 其它 |
|---|---|---|---|
| S 片回放成功（817） | `territory-ir` | `high` | — |
| 台账重演降级（851） | **`territory-ir-degraded`** | `low` | **必须带 `degraded_reason`**（原始异常文本） |
| 描述词兜底（约 894） | `ledger` | `low` | — |
| 草稿（约 938/1020） | `draft` | 按 `draft_quality` 映射 | — |

- `degraded_reason` 须包含**真实异常信息**（如 `ModuleNotFoundError/FileNotFoundError: ...`），
  不得写成"未知原因"之类的占位文本
- **所有** `/api/generate` 成功响应都必须带 `confidence` 字段（四条路径皆是）

### 2. 前端必须让降级可见（`tools/demo_page.html`）

`confidence !== "high"` 时：
- 围栏渲染改用**醒目告警配色**（与正常态明显区分）
- 页面显示提示条，写明**这是降级结果、精度可能显著偏低**，并展示 `degraded_reason`

参照本分支既有做法：T-004 已在 `intelligence/adjust.py` 用
`impact.area.granularity = "fence"|"piece"` 标注降级粒度，风格保持一致。

### 3. 降级须可观测

降级发生时，除响应字段外，同时写入服务端日志（保留现有 `print` 亦可，但需含时间与 area_id）。

### 4. 不得改变的行为

- 回放成功路径的响应内容除**新增** `confidence` 外，**其余字段一字不改**
- 不得改变任何路径的 HTTP 状态码（仍为 200）
- 不得改动 `intelligence/adjust.py`（T-004 已完成，勿动）
