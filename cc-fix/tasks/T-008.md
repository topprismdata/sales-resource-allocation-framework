## 根因（已定位，直接采信）

```python
Ut = STRtree([x[0] for x in U])          # :109 建好空间索引……全文仅此一处，从未被使用

def compile_fence(fence):
    zg = Polygon(fence["rings"][0])
    ...
    T = {k for k in range(len(U))                                    # ← 全量遍历 6,261 片
         if U[k][0].intersection(zg).area/max(U[k][0].area,1e-12) >= 0.5
         or U[k][0].intersection(zg).area/fa >= 0.3}                 # ← 同一片重复求交两次
    psel = {i for i in pt.query(zg) ...}                             # ← 紧邻一行却正确用了 pt 索引
```

同一函数内 parents 用了索引、U 没用。量级：6,261 片 × 2 次求交 × 90 组件 ≈ **113 万次几何运算**。

## 实现要求

### 1. 主优化：用已建好的 `Ut` 预筛

`STRtree.query(zg)` 返回**外接矩形相交**的候选超集；不与 `zg` 的 bbox 相交的片，
其 `intersection(zg).area` 必为 0，两个阈值条件都不可能满足
→ **预筛不会漏掉任何应入选的片，结果严格等价。**

### 2. 次优化：消除重复求交

同一片的 `U[k][0].intersection(zg)` 当前被计算两次，应只算一次并复用其 `.area`。

### 3. 允许但不强制的其它优化

可继续优化 `vocab()` / `clause_pieces()` / `feats_of()` 等热点，
**但必须满足下方 H1 的逐例等价门禁**。建议先测量再动手，不要盲目改写。

### 4. 必须保留暴力参考实现（供门禁比对）

在 `territory_compile.py` 中同时保留两份实现并导出：

