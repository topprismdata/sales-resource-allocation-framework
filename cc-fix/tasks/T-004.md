### 根因（`intelligence/adjust.py:95-113`）

```python
def _rows() -> list:
    global _ROWS
    if _ROWS is None:
        if _DATA_DIR is None:
            raise AdjustError("adjust 未初始化数据目录（set_data_dir）")
        path = _DATA_DIR / "territory_compiled.json"
        if not path.exists():
            raise AdjustError("缺少 territory_compiled.json（先跑 territory_compile.py）")
        _ROWS = json.loads(path.read_text(encoding="utf-8"))
    return _ROWS

def _row_of(dealer: str) -> dict:
    hit = next((r for r in _rows() if r.get("dealer") == dealer), None)
    if hit is None or not hit.get("S"):
        raise AdjustError(f"{dealer[:14]} 没有TerritoryIR编译结果（S片为空）…")
    return hit
```

RC2.0 把领地调整**硬绑定到离线编译产物**。测试以纯内存 World 构造
（`tests/test_multicomponent.py:make_world()`，3 个方形围栏 A1/A2/B1 + 12 门店），
既无 `_DATA_DIR` 也无 `territory_compiled.json`，遂全部抛 `AdjustError`。

**这不只是测试问题**：任何没有编译产物的部署，领地调整功能**完全不可用**。

### ★ 已实测的关键简化条件

5 个失败测试**全部只使用「整个区域」/「整体」选择器**：

| 测试 | 指令文本 |
|---|---|
| test_select_area_spans_components | 把经销商甲的**整个区域**划给经销商乙 |
| test_transfer_single_component | 把经销商乙的**整个区域**划给经销商甲 |
| test_transfer_multi_component_preserves_clusters | 把经销商乙的**整个区域**划给经销商甲 |
| test_transfer_zero_store_removal | 把经销商甲**整体**并入经销商乙 |
| test_proposal_multi_ring | 把经销商甲的**整个区域**划给经销商乙 |

而 `select_area_pieces` 的该分支是最简单的一条：
```python
if sel in ("全部","整体","所有","","不做了","退出","整个区域","整个"):
    return allp, "整个区域"
```
**不触及** `_piece_geom()`、`tc.U[k]` 街道标签、`_street_district_map()`。
→ 回退实现**无需重建单元库 U**，只需让「一个 fence = 一个 piece」。

## 实现要求

### 目标：无编译产物时降级到 fence 粒度，而非完全不可用

| 场景 | 行为 |
|---|---|
| 有 `territory_compiled.json` | **保持 RC2.0 现状，行为一字不改**（piece 粒度） |
| 无编译产物但有 World | **降级**到 fence 粒度：每个 fence 视作一个 piece |
| 两者皆无 | 仍抛 `AdjustError`（原样） |

### 设计要点（可自行选择实现方式，但须满足全部约束）

1. `select_area_pieces(world, dealer, selector)` **已持有 world**，
   可据此在无编译产物时构造等价结构：
   - 伪 row：`{"dealer": dealer, "S": [该 dealer 各 fence 的稳定 id]}`
   - piece 几何：由 `world.fences_by_dealer[dealer]` 各 `Fence.ring` 构造 Polygon
2. `_piece_geom()` / `_pieces_union()` 在降级模式下须返回上述 fence 几何
3. `build_proposal` 中的 `_row_of(src.dealer)["S"]`、`_rows()` 查 dst 计数
   两处也须在降级模式下工作
4. **降级必须显式可见**：`Proposal.impact["area"]` 中增加
   `"granularity": "fence"`（降级）或 `"piece"`（正常），
   使调用方与前端能区分调整精度。**禁止静默降级**——
   这是本分支的核心纪律（见 CONTRACTS §2）。

### 硬约束

- **不得改变有编译产物时的任何行为**（成功路径逐字节等价）
- **不得修改 `tests/` 下任何测试文件**——测试是既有契约，
