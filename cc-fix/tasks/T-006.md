## 目标

`tools/territory_compile.py:52` 读取 `{DATA}/gz_osm_full.json`，该文件缺失导致

本任务：由已备齐的原始数据生成该文件。

## 输入（均已存在，无需联网）

### 1. `data/gz/osm_raw.json`（59MB，已由架构层拉取完毕）

Overpass 原始响应，结构：
```json
{"elements": [
  {"type":"way","id":123,"tags":{"name":"广汕公路","highway":"primary"},
   "geometry":[{"lat":23.1,"lon":113.3}, ...]}
]}
```
实测：**72,836 条，全部带 `name`**。分布：
`tertiary 21465 / secondary 18113 / primary 15171 / motorway 8386 / trunk 7324 / waterway 2377`

### 2. `data/gz/source/区划数据-区县-广东省-广州市.geojson`

11 个 Polygon feature，`properties.行政区名称` 为区县名
（从化区/白云区/增城区/黄埔区/天河区/南沙区/番禺区/海珠区/…）。

## 输出：`data/gz/gz_osm_full.json`

```json
{
  "roads":  [{"name": "广汕公路", "cls": "primary", "wkt": "LINESTRING (113.3 23.1, ...)"}],
  "rivers": [{"name": "珠江",     "wkt": "LINESTRING (...)"}],
  "adm6":   [{"name": "天河区",   "wkt": "POLYGON ((...))"}]
}
```

消费方（`tools/territory_compile.py:67-86`，逐字对照，勿臆测）：
```python
for r in osm["roads"]:
    nm = r.get("name")
    g = wkt.loads(r["wkt"])
    _add_feat(nm, g, CLASS_RANK.get(r.get("cls","unclassified"), 7))
for r in osm.get("rivers", []):          # rivers 用 .get，可缺省
    g = wkt.loads(r["wkt"])
for rr in osm["adm6"]:                    # adm6 用 [] ，【必须存在】
    adm6.append((rr.get("name",""), wkt.loads(rr["wkt"]).boundary))
```

`cls` 取值须落在 `CLASS_RANK` 内：
`motorway/motorway_link/trunk/trunk_link/primary/primary_link/secondary/secondary_link/tertiary/tertiary_link/residential/unclassified/service`
（即直接取 OSM 的 `tags.highway` 原值即可）。

## ★★ 坐标系（最高风险项，误判代价 623m）★★

**本文件内部混用两种坐标系。这不是错误，是代码逻辑的硬要求。**

| 字段 | 坐标系 | 依据 |
|---|---|---|
| `roads` / `rivers` | **WGS-84** | `territory_compile.py:116` 先把 U（GCJ）转成 WGS 再与地物比对：<br>`gw = ops.transform(lambda x,y: gcj2wgs(x,y), U[k][0])`<br>`feat_geoms[j].distance(gw) <= FEAT_BUF` |
| `adm6` | **GCJ-02** | `adm6bt` 在 `compile_fence` 中与 `zg`/`pu`/`sbt`（全 GCJ）直接做几何运算：<br>`strip = zg.difference(pu).intersection(unary_union([sbt, adm6bt]).buffer(BAND_BUF))` |

**因此：两边都【不要】做任何坐标转换**——
OSM 数据本就是 WGS-84，本地区县 geojson 本就是 GCJ-02，各自原样写入即可。

> ⚠️ 若你"顺手"把两者统一到同一坐标系，会引入约 **623m** 系统偏移
> （实测值，见 CONTRACTS §1.1），且症状隐蔽——编译能跑完，只是地物贴附全错。

## 实现要求

新建 `tools/build_osm_full.py`，**幂等**，参数 `--data-dir`（默认经 `_paths` 解析），
从上述两个输入生成 `gz_osm_full.json`。

- `way` 的 `geometry`（`[{lat,lon},…]`）→ `LINESTRING (lon lat, …)`，**注意 WKT 是 lon 在前**
- 顶点数 < 2 的 way 跳过
- 无 `name` 的跳过（实测全部有 name，但仍需防御）
- `tags.waterway` 者归入 `rivers`，`tags.highway` 者归入 `roads`
- 区县 Polygon 含内环时须写成带内环的 WKT（`POLYGON ((外环), (内环))`）
